# OSN Off-Ramp API 集成测试脚本说明

## 文件说明

| 文件 | 说明 |
|------|------|
| `test_osn_offramp.py` | 测试主脚本 |
| `.api-key` | OSN API 密钥（已加入 .gitignore） |
| `sepolia_wallet.json` | Sepolia 测试网钱包（已加入 .gitignore） |

## 测试流程

脚本按顺序执行 7 个步骤，每步都有断言（assert）验证结果：

### 预检步骤

**步骤 1：检查收款银行账户**
- 调用 `GET /recipient-bank-account`
- 验证返回的账户列表非空
- 优先选择状态为 `approved` 的账户
- 打印账户名称和 ID

**步骤 2：检查可用钱包**
- 调用 `GET /users/me/wallets`
- 筛选出 Sepolia 链（`0xaa36a7`）且用途为 `user_organization_offramp_wallet` 的钱包
- 验证至少找到一个匹配的钱包
- 打印钱包地址和 ID

### 主流程

**步骤 3：创建报价（Quote）**
- 调用 `POST /payment-quotes`
- 参数：1.0 USDT → HKD，Sepolia 链
- 验证返回状态码 200/201
- 打印 Quote ID、汇率、过期时间

**步骤 4：创建转账（Transfer）**
- 调用 `POST /transfers`
- 使用步骤 1-3 获取的 bank_id、wallet_id、quote_id
- 验证状态为 `pending`
- 打印 Transfer ID 和 Payment ID

**步骤 5：链上打款**
- 使用 `sepolia_wallet.json` 中的私钥签名
- 通过 Onfinality RPC 发送 1.0 USDT 到 OSN 存款钱包
- 显示 ETH 和 USDT 余额
- 等待交易确认
- 打印 TX Hash 和区块号

**步骤 6：上传交易哈希**
- 调用 `PUT /transfers/{id}/upload-tx-hash`
- 字段名使用 `transaction_hash`（蛇形命名）
- 验证返回成功

**步骤 7：检查支付状态**
- 调用 `GET /payment-histories/status/{payment_id}`
- 打印当前状态（pending / processing / completed）
- 验证状态在合法范围内
- 之后每 10 秒轮询一次，最多 5 分钟，直到完成或失败

```bash
pip install requests web3
```

## 配置要求

- **`.api-key`**：一行文本，存放 OSN API 密钥
- **`sepolia_wallet.json`**：JSON 格式，包含 `private_key` 和 `address` 字段
- 钱包需要有足够的 Sepolia ETH（gas）和 USDT 余额

## 已知问题

- 每次运行会创建新的 Quote 和 Transfer，失败后可能产生孤儿转账记录
- 链上打款会消耗钱包的 USDT，请确保余额充足
- 支付完成（completed）通常需要 10-20 分钟，取决于 OSN 的结算速度
